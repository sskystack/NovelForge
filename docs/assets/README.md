# README media

`hero.svg` is an original vector banner using NovelForge's own book/pen-nib mark
and graphite/blue palette. Its miniature workspace is a decorative illustration;
the WebP files are actual 0.2.1 shared-frontend captures from isolated UI acceptance.

| File | Captured screen |
| --- | --- |
| `writing.webp` | 1440px manuscript and version inspector |
| `knowledge.webp` | Search results and selected source revision |
| `agent.webp` | Task trace with completed model work and a cancelled tool action |
| `onboarding.webp` | New-project wizard |
| `settings.webp` | Mock model settings with no configured key |
| `compact.webp` | 900px Mac-window layout with inspector open |

Screenshots use fabricated stories, synthetic test accounts, and mock/local protocol
providers. They contain no real manuscript or configured secret. Both language
READMEs share these assets; the UI is currently primarily Simplified Chinese.
Captures were resized to at most 1600px width and encoded as WebP for repository
display. No Agentero graphics, screenshots, logos, or community assets were copied.
